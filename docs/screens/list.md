# List

Receipts as text, one under another. The same work as the trail, written down instead of lit up. Opened from the list icon, top right of the trail view of Main.

**Newest first**, grouped by day. (The trail is the other way round: newest last, at the end of the path.)

## Tag filter

One filter, shared with the trail. Set it here or on the trail; it applies to both.

- Here, only matching receipts are shown.
- On the trail, only matching lights stay lit. The rest dim; they do not disappear.

Tags come from receipts, so a filter never shows an empty list. The filter stays set until you clear it, or until a new light is placed (see [main.md](main.md)).
