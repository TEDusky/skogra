# Detail

One receipt: date + tag + label + optional note. Opened from List (tap a receipt row) or from the trail (tap a light). Back returns to where you came from.

## Edit

Label, tag, and note can be edited. The date cannot. The label cannot be empty.

Editing does not change the trail. The light stays where it is and looks the same.

If you change the tag so it no longer matches the active filter, the receipt drops out of the filtered List when you go back.

## Delete

Asks first: **“Delete this receipt? Its light goes out.”**

On yes, the receipt and its light are gone. The trail closes up: the lights after it move back by one. Back to where you came from: List, or the trail at the spot where the light was.

| -------------- | --------------------------------------------------------- | ------------------------------------------------------------------- | ----------------------- |

| Date           | When it was finished.                                     | Display only.                                                       | —                       |
| Label          | What got finished.                                        | Edit.                                                               | Stays on Detail.        |

| Delete         | Mistakes happen.                                          | Confirm, then remove the receipt and its light.                     | List or Main (where you came from). |
