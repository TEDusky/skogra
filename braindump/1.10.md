Consulting my last todo, the next on the menu is trying to come up with list of possible screens (which will be turned into documentation later on), so let's get to that.

So what should the first thing user sees when he opens the app ?
The main focus of the screen should be "pomodoro like" timer. Timer can count down 3 things, short break, long break and flow.
On this screen, we should also be able to see what we are working on (and its tag), if the timer is active.
Also, we need something to set up these values, so settings screen. We can get there by clicking on cog icon in the top right screen of the main screen.
In the middle of the timer there is play / stop button. Above settings icon there is menu icon. (list view, trail view, about app)

After a long brainstorming session, I'm cutting everything in previous paragraph. On the one hand, it feels too simple, on other it feels too complex, like it's trying to be something it's not.
New plan is making everything happen at a single scrollable screen. User opens app, he sees timer with play button in the middle. There is no settings, no about. In the idle state, user can scroll down (like from sky to earth) on trail.
Trail is made out of things completed by focusing. Trail is horizontally scrollable and you can always return to the sky (timer).
After starting the timer, tag (optional), intention (optional) and time (defaults to 25:00) is set by the user. Screen then gets locked and is not scrollable anymore. You can stop the focus and this ends in prompt. If you finished something, it asks for another optional note, something you'd like to remember for this completed feat. If something was completed, you are automatically scrolled to the trail (and its end) and new object is added.

On the timer part of the main screen, we have a possibility to go to 'about screen'. This will present informations on what this app is, what it is not, why it exists and its version. From there on, you can only come back to main screen.
On the trail part of the main screen, we also have a possibility (via some list icon in the top right position of the screen) to view your completed focuses as a list. Here they could be sorted and filtered by tag and you can see them below each other. From there, you can return to 'main screen', or opren task detail.
